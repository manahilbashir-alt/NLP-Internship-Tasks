# Task 2: Comparative Analysis of Zero-Shot, One-Shot, and Few-Shot Prompting

## Objective

The objective of this task is to implement and compare three widely used prompting techniques in Large Language Models (LLMs): **Zero-Shot**, **One-Shot**, and **Few-Shot Prompting**. The comparison is performed across three Natural Language Processing (NLP) tasks: **Sentiment Classification**, **Named Entity Extraction**, and **Text Generation**.

---

# Introduction

Prompting techniques significantly influence the quality and consistency of responses generated by Large Language Models. Depending on the complexity of the task, providing examples within the prompt can improve the model's understanding of the expected output.

This experiment evaluates three prompting strategies:

- **Zero-Shot Prompting** – No examples are provided.
- **One-Shot Prompting** – One example is provided.
- **Few-Shot Prompting** – Multiple examples are provided.

The same NLP tasks are executed using each prompting technique to analyze their performance.

---

# Experiment 1: Sentiment Classification

## Objective

Determine the sentiment of a given sentence as **Positive**, **Negative**, or **Neutral**.

### Input Sentence

```text
I absolutely loved this movie. The acting was fantastic.
```

---

## Zero-Shot Prompt

```text
Classify the sentiment of the following sentence.

Sentence:
"I absolutely loved this movie. The acting was fantastic."

Return only:
Positive, Negative, or Neutral.
```

### Expected Output

```text
Positive
```

---

## One-Shot Prompt

```text
Example

Sentence:
"The food was terrible."

Sentiment:
Negative

Now classify the following sentence.

Sentence:
"I absolutely loved this movie. The acting was fantastic."

Return only:
Positive, Negative, or Neutral.
```

### Expected Output

```text
Positive
```

---

## Few-Shot Prompt

```text
Sentence:
"The weather is amazing."

Sentiment:
Positive

Sentence:
"The service was horrible."

Sentiment:
Negative

Sentence:
"The lecture was okay."

Sentiment:
Neutral

Now classify:

"I absolutely loved this movie. The acting was fantastic."

Return only:
Positive, Negative, or Neutral.
```

### Expected Output

```text
Positive
```

---

## Observation

The zero-shot prompt correctly identifies the sentiment but provides minimal guidance. One-shot prompting improves consistency by demonstrating the desired output format. Few-shot prompting establishes a clear pattern using multiple examples, resulting in the most reliable and structured response.

# Experiment 2: Named Entity Extraction

## Objective

Extract all named entities from the given sentence.

### Input Sentence

```text
Sundar Pichai is the CEO of Google and lives in California.
```

---

## Zero-Shot Prompt

```text
Extract all named entities.

Sentence:
Sundar Pichai is the CEO of Google and lives in California.

Return the entities under the following headings:

Person
Organization
Location
```

### Expected Output

```text
Person:
Sundar Pichai

Organization:
Google

Location:
California
```

---

## One-Shot Prompt

```text
Example

Sentence:
Ali studies at FAST University in Lahore.

Output

Person:
Ali

Organization:
FAST University

Location:
Lahore

Now extract entities from:

Sundar Pichai is the CEO of Google and lives in California.
```

### Expected Output

```text
Person:
Sundar Pichai

Organization:
Google

Location:
California
```

---

## Few-Shot Prompt

```text
Sentence:
Sara works at Microsoft in Seattle.

Person:
Sara

Organization:
Microsoft

Location:
Seattle

Sentence:
Ahmed studies at FAST University in Islamabad.

Person:
Ahmed

Organization:
FAST University

Location:
Islamabad

Now extract entities from:

Sundar Pichai is the CEO of Google and lives in California.
```

### Expected Output

```text
Person:
Sundar Pichai

Organization:
Google

Location:
California
```

---

## Observation

Providing examples significantly improves formatting consistency. Few-shot prompting produces the most organized and accurate extraction.

# Experiment 3: Text Generation

## Objective

Generate a professional email requesting a project deadline extension.

---

## Zero-Shot Prompt

```text
Write a professional email requesting a project deadline extension.
```

---

## One-Shot Prompt

```text
Example

Write a professional leave request email.

Now write a professional email requesting a project deadline extension.
```

---

## Few-Shot Prompt

```text
Example 1

Write a formal internship acceptance email.

Example 2

Write a professional meeting request email.

Example 3

Write a formal leave application.

Now write a professional email requesting a project deadline extension.
```

---

## Observation

Zero-shot prompting generates a reasonable email but may vary in style. One-shot prompting produces a more formal structure, while few-shot prompting consistently generates professional and well-organized content.

---

# Comparative Analysis

| Feature | Zero-Shot | One-Shot | Few-Shot |
|----------|-----------|-----------|-----------|
| Number of Examples | 0 | 1 | Multiple |
| Prompt Length | Short | Medium | Long |
| Ease of Design | High | High | Moderate |
| Output Consistency | Medium | High | Very High |
| Response Accuracy | Medium | High | Very High |
| Best Use Case | Simple Tasks | Moderately Complex Tasks | Complex Structured Tasks |

---

# Key Findings

- Zero-shot prompting is effective for simple and well-defined tasks.
- One-shot prompting improves consistency by demonstrating the expected response format.
- Few-shot prompting consistently produces the highest-quality outputs by allowing the model to learn patterns from multiple examples.
- Well-structured prompts reduce ambiguity and improve response quality.

---

# Conclusion

This comparative study demonstrates that prompt design plays a critical role in the performance of Large Language Models. While zero-shot prompting is sufficient for straightforward tasks, one-shot and few-shot prompting provide additional guidance that enhances response quality. Among the three techniques, few-shot prompting produced the most accurate, structured, and reliable outputs across all evaluated NLP tasks, making it the preferred approach for complex language understanding and generation tasks.
