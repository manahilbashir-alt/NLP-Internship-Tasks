# Task 1: Study and Implement the Core Prompt Anatomy

---

# Objective

The objective of this task is to study and implement the fundamental building blocks of prompt engineering. A well-structured prompt provides clear instructions to a Large Language Model (LLM), resulting in responses that are more accurate, relevant, and consistently formatted.

---

# Introduction

Prompt engineering is the process of designing effective prompts that guide an AI model toward producing high-quality outputs. Instead of asking vague questions, a structured prompt supplies sufficient information about the AI's role, the background context, the desired task, examples of expected behavior, and formatting requirements.

A complete prompt generally consists of the following five components:

1. Role / Persona
2. Context
3. Task / Instruction
4. Examples
5. Output Format Constraints

---

# Core Prompt Anatomy

## 1. Role / Persona

The Role component defines the identity or expertise the AI should assume before answering.

### Example

```text
You are an experienced NLP professor.
```

### Purpose

- Defines the AI's expertise.
- Influences tone and vocabulary.
- Produces more domain-specific responses.

---

## 2. Context

Context provides background information that helps the AI understand the situation.

### Example

```text
The audience consists of first-year Computer Science students with basic Python knowledge.
```

### Purpose

- Reduces ambiguity.
- Adapts explanations to the intended audience.
- Improves response relevance.

---

## 3. Task / Instruction

The task clearly specifies what the AI should accomplish.

### Example

```text
Explain the concept of TF-IDF, its importance, and its real-world applications.
```

### Purpose

- Clearly defines the objective.
- Prevents incomplete or irrelevant responses.

---

## 4. Examples

Examples demonstrate the expected writing style or reasoning pattern.

### Example

```text
Explain Bag of Words using a library analogy before introducing TF-IDF.
```

### Purpose

- Guides the model toward the desired style.
- Produces more consistent outputs.

---

## 5. Output Format Constraints

Output constraints define how the response should be organized.

### Example

```text
• Use headings
• Use bullet points
• Include one real-world example
• Maximum 250 words
```

### Purpose

- Ensures consistency.
- Improves readability.
- Makes responses easier to evaluate.

---

# Implementation

To demonstrate prompt anatomy, the same topic ("Explain TF-IDF") was progressively enhanced by adding prompt components one by one.

---

## Prompt Version 1 — Basic Prompt

```text
Explain TF-IDF.
```

**Observation**

- Generic response
- No defined audience
- Unstructured output

---

## Prompt Version 2 — Role Added

```text
You are an experienced NLP professor.

Explain TF-IDF.
```

**Observation**

- More educational tone
- Better technical explanation

---

## Prompt Version 3 — Role + Context

```text
You are an experienced NLP professor.

The audience consists of first-year Computer Science students.

Explain TF-IDF.
```

**Observation**

- Simpler language
- Beginner-friendly explanation
- Improved relevance

---

## Prompt Version 4 — Complete Prompt Anatomy

```text
Role:
You are an experienced NLP professor.

Context:
The audience consists of first-year Computer Science students.

Task:
Explain TF-IDF, why it is important, and where it is used.

Example:
Use a library analogy before explaining TF-IDF.

Output Format:
- Use headings
- Use bullet points
- Include one real-world example
- Maximum 250 words
```

---

# Conclusion

This experiment demonstrates that prompt quality significantly influences the quality of responses generated by Large Language Models. Adding Role, Context, Task, Examples, and Output Format constraints progressively improves clarity, structure, relevance, and consistency. The complete prompt anatomy produced the most informative and well-organized response, highlighting the importance of effective prompt engineering in real-world AI applications.
